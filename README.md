# Frame Studio

Frame Studio is a modern web studio focused on creating visually engaging websites with unique animations and experimental design techniques.

Our goal is to push the boundaries of what websites can feel like by combining modern development tools, smooth interactions, and creative visual storytelling.

---

## 🚀 About the Project

Frame Studio is a portfolio and showcase platform where we present websites built with modern technologies and creative animation systems.

The platform allows visitors to explore different projects, view design approaches, and experience the interactive elements that make each website unique.

Each project highlights:

* Modern UI/UX design
* Smooth animations and motion systems
* Experimental layouts
* Performance-focused development

---

## ✨ Features

* Animated and interactive website showcases
* Modern responsive design
* Admin dashboard for managing projects
* Dynamic project loading from database
* Clean and minimal user interface

---

## 🛠 Technologies Used

This project is built using modern web technologies:

* React
* Supabase (Database & Authentication)
* Motion / Animation libraries
* TypeScript
* Modern CSS / Tailwind-style utilities

These tools allow Frame Studio to experiment with new interaction patterns while keeping performance high.

---

## 🎨 Vision

Frame Studio is not just about building websites.

It is about exploring new creative directions in web development, experimenting with animation systems, and designing digital experiences that feel modern, expressive, and memorable.

The studio aims to combine technology and creativity to build websites that stand out.
